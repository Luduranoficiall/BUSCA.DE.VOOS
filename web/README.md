# Aurora Travel Web

Landing page e SEO programático para Aurora Travel.

- Next.js 14
- SEO automático por rota/destino
- Deploy Vercel

## Estrutura
```
web/
├── app/
│   ├── page.tsx
│   ├── [from]/[to]/page.tsx
│   └── sitemap.ts
├── components/
├── lib/seo.ts
├── package.json
├── next.config.js
```

## Como rodar

```bash
cd web
npm install
npm run dev
```

## Deploy

Deploy recomendado: Vercel (1-click)
